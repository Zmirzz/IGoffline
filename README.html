IGoffline Direct

IGoffline Direct is a pure frontend Instagram Direct archive viewer. It recreates the familiar DM interface for your exported data so you can revisit conversations without logging into Instagram. All processing happens client-side – no analytics, servers, or uploads.

Key Features

  • Inbox-style layout with avatars, previews, and relative timestamps.
  • Drag & drop imports for entire messages folders or individual message_X.json files.
  • Identity selection so the app knows which side of the chat to style as “you”.
  • Message detail rendering covering text, links, reactions, calls, story shares, and attachment summaries.
  • Conversation filtering via a quick search box on the sidebar.
  • Merged JSON export to save the normalised dataset for reuse elsewhere.

How to Use

  1. Request your Instagram data download, unzip it, and locate the messages/inbox directory.
  2. Open index.html in a modern desktop browser (Chrome, Edge, Firefox, Safari 15+).
  3. Drag the messages folder—or any selection of message_X.json files—onto the window, or click Import archive and pick them manually.
  4. Choose your own account name from the identity picker so outgoing messages receive the right-hand bubble styling.
  5. Pick a conversation in the sidebar to browse the full thread. Use the search bar above to filter by participant or title.
  6. Hit Export merged JSON anytime you want to download the combined, normalised conversations.

Tip: Large archives import faster in batches. You can drag more files in later—the viewer merges them into existing threads automatically.

Data Notes

  • Each message_X.json file is grouped by its thread_path, matching Instagram’s folder layout.
  • Media (photos, videos, audio, files) are not auto-loaded, but their presence is listed along with the export-relative URIs so you can open them manually.
  • The export function preserves the parsed data plus the original raw message fields, ready for further scripting.

Extending the Viewer

  • To load zipped exports directly, bundle a client-side decompression library (e.g. fflate, JSZip) and feed the extracted JSON into the existing import pipeline.
  • For inline media previews, use the stored uri paths to fetch the corresponding files (placing them next to the app or leveraging the File System Access API).

Browser Support

Tested on the latest Chrome/Edge, Firefox, and Safari 15+. Mobile browsers may limit folder drops or large file parsing.
